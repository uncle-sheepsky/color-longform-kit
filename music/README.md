# music/ — 「WHAT YOUR COLOR.」 롱폼 음악(CC0)

- `color_longform.wav` — 완성 곡(80.000초 · 48kHz 스테레오 · 통합 −14.0 LUFS · 트루피크 −2.0 dBTP · 44.17~45.33초 완전 무음). 영상에 그대로 넣는 파일. CC0.
- `build_music.py` — 이 곡을 만드는 코드(화성 · 선율 · 편곡 · 구간 크기 · 마스터). 다시 돌리면 같은 WAV 가 바이트까지 똑같이 나옵니다(이 키트를 만든 컴퓨터에서 SHA256 `df52fb17…` 확인).
- `band.py` — 저수준 엔진(샘플 재생 · 박 → 초 · 스윙 · 코드 보이싱 · 리버브 · 리미터 · 라우드니스) · `sfz_sampler.py` — SFZ 파일 읽기.

## 다시 만들기(바꾸고 싶을 때)
1. 실제 악기 샘플 **VSCO 2 Community Edition**(CC0 · 약 3GB)을 받습니다: https://github.com/sgossner/VSCO-2-CE/releases/tag/1.1.0
2. 푼 폴더를 `music/VSCO-2-CE-SFZ/` 에 두거나, 환경변수 `VSCO_SFZ_DIR` 에 그 폴더 경로를 넣습니다(그 아래 어디든 `.sfz` 파일만 있으면 됨).
3. `python music/build_music.py` → `music/out/longform/mix.wav` (+ `report.json` · `stems/`)
4. 영상에 넣기: `python tools/finish.py --music music/out/longform/mix.wav`

쓰는 악기: SViolinVib(솔로 바이올린) · ViolinEnsPizz/Spic/SusVib/Trem · ViolaEnsSusVib · CelloEnsSpic/SusVib · ContrabassPizz/SusVB · ClarinetSus · BassoonSus · FluteSusVib · FHornSus · TrumpetSus/Stac/StraightMuteSus · TromboneStac · Harp · Marimba · Timpani(Rolls) · GM-StylePerc(관현악 북 · 심벌).

## 음악을 바꿀 때 지킬 것(이 곡을 만들며 정한 규칙)
- **화면 사건은 음악 박에 맞춘다.** 음악이 그 박에 사건을 만들지 않았다면 효과음으로 화면을 따라 치지 않는다(글자마다 「띵」 같은 소리는 오히려 충돌).
- **대선율은 주선율이 화음음으로 머물 때만** 16분 늦게 · 3도 이상 아래 · 2도 · 7도 · 증4도로 겹치지 않게(`counter()` · 보고서 `clash` 가 겹침을 셈).
- **스윙을 쓰면 음 길이도 스윙 위치로 셈다**(다음 음 시작까지) — 박 단위로 세면 박 위 음마다 틈이 생겨 톡톡 끊김(`lead()`).
- 주선율 ≤ MIDI 76(너무 높으면 귀가 아픔) · 흔드는 타악(셰이커 · 방울)을 깔지 않음.
- 구간 크기는 손으로 키우지 않고 목표 아치(`TARGET`)에 맞춰 자동 배율 · 마지막에 통합 −14 LUFS · 트루피크 ≤ −1.5 로 맞춤 · 무음 구간은 리버브 꼬리까지 통째로 0.
