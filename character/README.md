# character/ — 여기에 원하는 캐릭터를 넣으세요

이 템플릿은 **여기 넣은 캐릭터로 영상을 만듭니다.** 동작 하나 = 폴더 하나.

```
character/
  stand/     00.png 01.png …   (서 있기 — 가장 많이 나옴 · 장 순서대로 재생)
  surprise/  00.png …
  cheer/     00.png …
```
그림 1장만 있어도 됩니다: `character/main/00.png` (또는 `character/main.png`) — 모든 장면이 이 그림을 씁니다.

## 그림 조건
- 투명 바탕 PNG(또는 WEBP) · 한 폴더 안의 장은 **같은 캔버스 크기**(같은 자리에 겹쳐 그린 동작).
- 크게 그릴수록 좋습니다: 얼굴 클로즈업이 화면 키의 2~4배까지 확대됩니다. 캐릭터 키 **1,000px 이상** 권장(작으면 키워서 쓰지만 흐려짐).
- 색은 그림에서 자동으로 뽑습니다. 이런 그림이 잘 됩니다:
  - 선이 진하고 또렷함(가장 어두운 색 = 선)
  - 몸 바탕이 밝은 한 색(= 종이색 — 「선만 남은」 판에서 이 색으로 칠함)
  - **뚜렷한 색 2~3가지**(옷 · 소품 · 볼 등 — 하나씩 돌아오는 색)
  - (있으면) 선보다 밝은 진한 면(머리카락 · 뿔 · 신발 등) — 44초 정적 장면에 이 덩어리가 크게 나옴. 없으면 가장 큰 키컬러 덩어리를 씀
  - 그림자 · 그러데이션이 많은 그림은 색이 여러 묶음으로 갈려 층이 지저분해질 수 있음 → `build/check.png` 로 확인
- 장 사이 시간 = `config.json` 의 `frame_ms`(기본 100ms).

## 어느 장면에 어떤 동작이 쓰이나(자리 = slot)
장면 코드는 아래 **자리 이름**으로 동작을 부릅니다. 같은 이름의 폴더가 있으면 그걸 쓰고, 없으면 오른쪽 「대신」 순서로 찾아 쓰고, 끝내 없으면 `stand`(그것도 없으면 첫 폴더)를 씁니다. 내 폴더 이름이 다르면 `config.json` 에 `"poses": {"surprise": "놀람", "cheer": "만세"}` 처럼 이어 주세요.

| 자리 | 어울리는 동작 | 나오는 곳 | 대신 |
|---|---|---|---|
| `stand` | 서 있기(★ 기본 · 0번 장이 기준) — **2번 장 = 눈 감은 장**이면 깜빡임이 됨 | 1구간 그려지는 캐릭터 · 자리 찾기 · 여러 곳 | — |
| `ready` | 두 손 모음 · 기다림 | 1 · 2구간 · 6구간 실루엣 | stand |
| `surprise` | 놀람(얼굴이 크게 나옴) | 2구간 얼굴 클로즈업 · 3구간 | stand |
| `wave` `shy` `peek` `tickle` | 손 흔들기 · 수줍음 · 빼꼼 · 간지럼 | 2 · 3구간 격자 · 구도 | stand |
| `play` `play_lean` `play_mash` `play_bomb` | 게임 스틱을 쥔 동작(기다림 · 기울임 · 연타 · 폭탄!) | 2구간(리듬게임) · 5구간 테트리스 옆 | ready / play … |
| `cheer` `thanks` `congrats` `cold` `eat` `coffee` `hot` `no` `hug` `love` `lift` `gift` | 환호 · 고마움 · 축하 · 추위 · 먹기 · 커피 · 더위 · 아니 · 안기 · 하트 · 들기 · 선물 | 3구간 색마다 구도 · 몰아치기 · 5구간 드롭 | stand(congrats · lift → cheer) |
| `clap` | 박수 직전(두 손이 벌어진 장) | 끝 화면 박수 전 | ready → stand |
| `end` | 끝 화면 자세(박수 친 뒤 · 썸네일이 될 그림) | 끝 화면 | stand |

자리마다 「동작의 몇 번째 장」을 쓰는 곳이 있습니다(예: `surprise` 0 → 2 → 4 → 5번 장). 장이 그보다 적으면 앞 장으로 돌아가 씁니다(5장짜리면 5번 = 0번).
