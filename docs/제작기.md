# 제작기 — 「WHAT YOUR COLOR.」 롱폼을 만들며 바꾼 것(2026-11-12 ~ 11-14)

유튜브 채널 「아낌없이 주는 두루」의 롱폼을 채널 운영자와 Claude 가 사흘 동안 만든 기록입니다. 그림 · 주제 · 판정은 운영자, 화면 코드 · 음악 코드는 Claude. 「 」 안은 운영자의 말 그대로입니다.
결과 코드가 왜 지금 모양인지 궁금할 때 읽으세요. 따라 만드는 데는 필요 없습니다.

## 출발 — 숏폼의 긴 판
- 20초 숏폼 「WHAT YOUR COLOR.」(선만 남은 캐릭터에게 색이 하나씩 돌아옴)을 먼저 냈고, 운영자가 「기존 숏폼이 방향성은 좋은데 주제의식이 영상에서는 잘 드러나지 않는 것 같아서」 긴 판을 시작했습니다.
- 새로 필요한 그림을 Claude 가 다른 AI 에 대신 주문했지만 「캐릭터가 이상」해서 버리고, 운영자가 직접 다시 만들어 왔습니다(두루 그림은 GPT 로 만든 그림입니다). 형식 검사는 생김새를 판정하지 못한다는 걸 여기서 배웠습니다.

## 1차 시안과 주제 고쳐 잡기(11-12)
- 시안 v1(♩150 · 1:42): 「트렌지션도 너무 아쉽고 · 이미지도 중간 중간 끊긴 느낌이 강해 · 레퍼런스의 느낌도 죽었고 · 주제의식도 아쉬워 · 근데 장면만 프레임 별로 놓고 보면 괜찮은 구도가 많아」.
- 재 보니 끊김은 대부분 **같은 구도에서 그림만 갈아 끼운 컷**(33곳)이었습니다.
- Claude 가 지어 붙인 주제(「색은 한 일에서 배어 나온다」)는 틀렸고, 주제는 운영자 몫이었습니다: 「색을 찾아가는 두루처럼 되길 원했어, 마치 정체성을 헤매는 사람들처럼. 그렇다고 우울한 분위기를 직설적으로 던질 필요는 없어」 · 썸네일이 이미 그 느낌(「인간찬가를 외치지 않는 찬가」)을 갖고 있으니 「그 썸네일의 이미지가 자연스럽게 만들어져 가는 과정」을 따라가면 된다.
- 그래서 끝 장면 = 썸네일 구도가 조각조각 만들어지는 과정이 되었고, 처음 화면의 비스듬한 흰 선이 끝의 경계선(반은 선 · 반은 색)이 됩니다.

## 앞부분 열 번(11-13)
- 진행 방식을 바꿈: 「1~2 · 3~4 · 5~6 구간으로 나누어 제작하여 완성도에 집중」 · 「사용자 승인이 있기까지 각 구간은 제작 완성처리하지 않습니다」.
- 1~2구간은 열 번째에 승인됐습니다. 걸렸던 것:
  - 코드 도형으로 캐릭터 얼굴을 짓는 화면 — 「이 도형으로 구성된 화면 자체가 퀄리티가 떨어짐 · 연출로는 극복할 수 없는 짜침」 → 코드 도형으로 캐릭터를 짓지 않음. 캐릭터는 늘 운영자가 준비한 그림.
  - 「아예 1구간이 하이라이트라 생각하고 급발진을 해」 뒤 반 박 몽타주 — 「연출도 별로고 정신만 사나움」 · 「두루만 많이 나온다고 좋은 게 아님」 → 화면엔 캐릭터 한 마리 · 색은 하나씩 · 격자는 구간마다 한 번.
  - 승인된 문법 = 어두운 바탕 · 펜 빛이 선을 그림 · 남의 색은 원판이 툭 + 발치부터 차오름(원판은 반 박 늦게) · 색마다 구도를 바꿈.

## 가운데와 끝(11-14 오전)
- 3~4구간 v1(단조로움) · v2(새 세계) 모두 헤맴 → 「차라리 쇼츠 스타일을 쭉 따라해보는 건 어때 · 계속 헤매는 것 같은데」 → 올린 숏폼의 흐름을 그대로 늘려 앉혀 승인. 교훈: 매번 새로 발명하지 말고 이미 승인된 문법을 늘린다.
- ♩150 → **♩180**: 「올린 숏폼이랑 비교하면 음악 속도부터 너무 큰 차이」 + 참고 영상 두 편 · 「심볼릭 · 아이코닉 살려줘 · 은하 연산 같은 장치」 → 아이콘을 캐릭터를 짓는 데가 아니라 장치의 몸으로(`devices.js`: 은하 · 탄막 · 수박식 물리 · 리듬 노트).
- 박마다 「동그라미로 열림」의 첫 프레임이 화면 전체 색이라 번쩍임 기준에 닿음 → 넓게 열린 원에서 시작.
- v5: 지적 여섯 곳만(「지적한 부분 외 임의로 고치지 말 것 · 지금 꽤 좋은 느낌」). 옛 게임 화면을 그대로 재현한 테트리스 · 블랙홀은 「옛날 영상 연출을 너무 그대로 · 기능만」 → 우물 테 · 점수판 없이 기능만.
- v6: 액자 든 캐릭터 · 블랙홀 속 캐릭터는 없는 게 나음 → 원판 자체가 창 · 블랙홀엔 색과 아이콘만. 위쪽 얼굴 카드 · 숫자 HUD 대신 연한 코드 글자가 쳐지며 흐름. 빛 구간 입자 흡수 = 머리 둘레 → 해 아래 → 해 뒤로(운영자 스케치) · 점마다 깊이로 앞뒤 층을 정함.
- v7: 「영상 전반 아주 좋고 만족 · 유사 장면 단순 반복 아쉬움」 → 샷 길이를 2 · 1 · ½박으로 섞고 좌우 자리 · 들어오는 방향을 변주. 41~44초 얼굴 더듬기 → 「자리 찾기」(색 조각이 제자리를 찾아 딸깍).
- v8 영상 승인: 끝 구간을 「순차가 아니라 키프레임처럼 약간의 시간차로 동시에 시작해 맞물리게 · 칼같이 구분 짓지 말 것」.
- v9: 57~71초 빛 구간을 1.67배속.
- v10: 「41초의 면만 뺀 두루 뿔이 아주 좋음」 → 44초 정적에서 선 소용돌이 대신 그 면이 「선을 대신해서 · 크기는 선의 영역만큼」 감기며 등장. 교훈: 좋다고 한 것은 보조가 아니라 주인공 자리로. (키트에서는 「가장 큰 진한 면 덩어리」를 자동으로 떼어 씁니다.)

## 음악(11-12 ~ 11-14)
- v1 = 숏폼 주제를 이어받은 합성 칩 곡 → ♩180 판(v2) → 운영자 청취 지시(드롭 악기 단독 소리 들어 보기 · 글자마다 방울 빼기 · 빛 구간 또렷하게) → v4 「대선율 주선율 박자가 안 맞으면서 불협 · 충돌」 → 대선율은 주선율이 머물 때만(앞 · 가운데 · 뒤 나눔).
- v7: 「1시간 롱폼 음악은 신선했는데 지금은 옛날 느낌」 → 원인(합성 칩 위주 · 세계를 먼저 안 정함 · 같은 진행 반복) → 「다시 짜 봐」 → 세계부터: 종이 미술실의 실내 악단 · 실제 악기 녹음(VSCO 2 CE) · 색 하나 = 악기 하나 · 안달루시아 하강 + 스윙.
- v8: 「8~17초 각 음 끝에서 악기가 살짝 일찍 끝나 톡톡 끊김」 → 원인 셋(짧은 음 녹음 · 음 길이를 스윙 전 박으로 셈 · 급한 꼬리) → 이어 잇기 · 긴 화음 · 활 저음 시안 중 하나를 고르고, 주선율 악기 네 가지를 비교해 운영자가 솔로 바이올린을 고름.
- 11-14 운영자 「이걸 최종으로」 — 영상 v10 + 음악 v8.
